# NEXORA GROUP — Multi-Venture Corporate Portfolio

A modern, high-performance corporate multi-venture portfolio web platform engineered with **Next.js 15 (App Router)**, **TypeScript**, and **Tailwind CSS**. Uniting specialized enterprises across AI platforms, immersive media art, next-generation CG production, and contemporary fashion.

## Features

- **Dynamic Homepage & Design**: Sleek dark aesthetic with atmospheric circuit textures, venture highlights, and interactive preview modals.
- **Ventures Portfolio**:
  - **Rozena**: AI fashion fitting (AIVALAPS®) & soft-grunge fashion curation.
  - **Damgara**: STORYSYNC real-time AI media art facade experiences.
  - **Nextep**: 3D engine & CG video production, VR/AR/MR.
  - **Noeul**: Contemporary minimalist Seoul fashion label.
- **Admin Dashboard**: Content management, video job generation pipelines, and site settings.
- **AI Video Studio**: Multi-provider AI generation pipeline support (Luma Dream Machine, Fal.ai, Replicate).

## Getting Started

First, install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

## Environment Setup

Copy `.env.example` to `.env.local` and set your credentials:

```bash
cp .env.example .env.local
```
